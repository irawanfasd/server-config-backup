# 📁 MIDNIGHT COMMANDER (MC) - PANDUAN CEPAT

## 🚀 CARA MENJALANKAN
- Ketik `mc` lalu tekan **Enter** untuk membuka program

## 🧭 NAVIGASI
- Gunakan **tombol Panah** untuk berpindah file/folder
- Tekan **Enter** untuk masuk folder

## 🔄 GANTI PANEL
- Tekan **Tab** untuk pindah kursor antar panel kiri dan kanan

## ⌨️ TOMBOL PINTAS UTAMA (F-KEYS)

| Tombol | Fungsi |
|--------|--------|
| **F4** | Edit file |
| **F5** | Salin (Copy) file |
| **F6** | Pindah (Move/Rename) file |
| **F7** | Buat folder baru |
| **F8** | Hapus file/folder |
| **F10** | Keluar dari program |

## 📌 TIPS TAMBAHAN
- **Ctrl+O** : Lihat output terminal (shell)
- **Ctrl+R** : Refresh panel
- **Ctrl+X, I** : Info permission file
- **Alt+Enter** : Copy nama file ke command line
